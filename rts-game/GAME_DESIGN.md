# Game Design Document - RTS Multiplayer Game

## Концепция игры

### Тематика
Игра представляет собой метафору работы компьютерных программ, борющихся за ресурсы системы. Каждый элемент игры соответствует реальной концепции программирования.

### Целевая аудитория
- Студенты изучающие программирование
- Разработчики, интересующиеся игровым обучением
- Игроки, любящие стратегии в реальном времени

## Игровые механики

### Основной игровой цикл

1. **Накопление ресурсов** (Memory)
   - Захват узлов памяти через юниты-Allocator
   - Пассивное производство от захваченных узлов
   - Расход на разыгрывание карт

2. **Стратегическое планирование**
   - Выбор карт из руки (5 карт)
   - Решение о типе юнитов для создания
   - Планирование атак и защиты

3. **Тактическое исполнение**
   - Размещение юнитов на поле
   - Управление движением
   - Атака вражеских юнитов и построек

4. **Достижение победы**
   - Уничтожение вражеской базы (Instance)

### Система ресурсов

#### Memory (Память)
- **Начальное количество**: 100
- **Максимум**: 500
- **Производство**: 
  - RAM узел: 10/сек
  - CACHE узел: 15/сек
  - HEAP узел: 8/сек
  - STACK узел: 5/сек

#### Стоимость юнитов
- **Basic Process**: 30 Memory
- **Allocator**: 50 Memory
- **Garbage Collector**: 40 Memory
- **Polymorph Warrior**: 70 Memory
- **Lambda Sniper**: 85 Memory
- И т.д. (см. UnitType.kt)

### Типы юнитов

#### 1. Basic Processes (Базовые процессы)
**Философия**: Фундаментальные операции системы

- **Allocator**
  - Роль: Захватчик ресурсов
  - Механика: Захватывает узлы памяти, производит Memory пассивно
  - Тактика: Первый юнит для захвата карты
  
- **Garbage Collector**
  - Роль: Поддержка и очистка
  - Механика: Очищает "мусор", возвращает память
  - Тактика: Экономичный саппорт
  
- **Basic Process**
  - Роль: Базовая пехота
  - Механика: Дешевый боевой юнит
  - Тактика: Массовые атаки

#### 2. OOP Units (Объектно-ориентированное программирование)
**Философия**: Принципы ООП в действии

- **Inheritance Drone**
  - Концепция: Наследование
  - Механика: Поглощает павших союзников, наследует их лучшие характеристики
  - Синергия: Сильнее при наличии разнообразных союзников
  
- **Polymorph Warrior**
  - Концепция: Полиморфизм
  - Механика: Адаптирует тип атаки под цель
  - Синергия: Универсальный боец
  
- **Encapsulation Shield**
  - Концепция: Инкапсуляция
  - Механика: Создает защитный барьер, скрывает союзников
  - Синергия: Защита хрупких юнитов
  
- **Abstraction Agent**
  - Концепция: Абстракция
  - Механика: Скрывает союзников от врага
  - Синергия: Тактические маневры

#### 3. Reflection & Metaprogramming (Рефлексия и метапрограммирование)
**Философия**: Самоанализ и модификация кода

- **Reflection Spy**
  - Концепция: Рефлексия
  - Механика: Сканирует вражеские юниты, раскрывает характеристики
  - Тактика: Разведка перед атакой
  
- **Code Injector**
  - Концепция: Метапрограммирование
  - Механика: Внедряет баги во вражеские фабрики
  - Тактика: Саботаж производства
  
- **Dynamic Dispatcher**
  - Концепция: Динамическая диспетчеризация
  - Механика: Увеличивает скорость (CPS) союзников в радиусе
  - Тактика: Буфф-юнит для атак

#### 4. Asynchrony & Parallelism (Асинхронность и параллелизм)
**Философия**: Многозадачность и конкуренция

- **Coroutine Archer**
  - Концепция: Корутины
  - Механика: Асинхронные стрелы, пробивающие защиту
  - Тактика: Обход бронированных целей
  
- **Promise Knight**
  - Концепция: Промисы/Future
  - Механика: При гибели создает отложенный урон
  - Тактика: Камикадзе с отложенным эффектом
  
- **Deadlock Trap**
  - Концепция: Дедлок
  - Механика: Обездвиживает несколько атакующих юнитов одновременно
  - Тактика: Оборонительная ловушка

#### 5. Functional Programming (Функциональное программирование)
**Философия**: Чистые функции и иммутабельность

- **Lambda Sniper**
  - Концепция: Лямбда-функция
  - Механика: Смертельный однократный выстрел (чистая функция)
  - Тактика: Снайпер для высокоценных целей
  
- **Recursive Bomb**
  - Концепция: Рекурсия
  - Механика: При взрыве создает две меньшие бомбы
  - Тактика: AOE урон с эскалацией
  
- **Higher-Order Commander**
  - Концепция: Функции высшего порядка
  - Механика: Усиливает союзников, "принимая их как функции"
  - Тактика: Командный центр для армии

#### 6. Network & Communication (Сетевые протоколы)
**Философия**: Взаимодействие и передача данных

- **API Gateway**
  - Концепция: API Gateway
  - Механика: Расширяет радиус действия союзников
  - Тактика: Увеличение влияния армии
  
- **WebSocket Scout**
  - Концепция: WebSocket
  - Механика: Постоянно передает координаты вражеских юнитов
  - Тактика: Перманентная разведка
  
- **RESTful Healer**
  - Концепция: REST API
  - Механика: CRUD операции для лечения
    - GET: Диагностика
    - POST: Лечение
    - PUT: Усиление
    - DELETE: Снятие дебаффов
  - Тактика: Универсальный медик

#### 7. Storage & Data Structures (Хранилища)
**Философия**: Управление данными и состоянием

- **Cache Runner**
  - Концепция: Кэш
  - Механика: Быстрый юнит с малым HP, захватывает кэш-узлы
  - Тактика: Быстрый захват ресурсов
  
- **Indexer**
  - Концепция: Индексирование
  - Механика: Маркирует цели, повышает урон союзников по ним
  - Тактика: Поддержка фокус-таргета
  
- **Transaction Guard**
  - Концепция: Транзакции (ACID)
  - Механика: При смерти откатывает захват узла к предыдущему состоянию
  - Тактика: Защита захваченных территорий

## Карточная система

### Типы карт

1. **SPAWN_UNIT**
   - Создание конкретного типа юнита
   - Стоимость = стоимости юнита
   - Требует свободную фабрику

2. **FACTORY_UPGRADE**
   - Улучшение фабрики (увеличение скорости, разблокировка юнитов)
   - Стоимость: 100 Memory
   - Эффект постоянный

3. **DIRECT_DAMAGE**
   - Прямой урон по цели
   - Стоимость: 40 Memory
   - Урон: 80 HP

4. **HEAL**
   - Лечение союзного юнита
   - Стоимость: 30 Memory
   - Восстановление: 50 HP

5. **BOOST**
   - Временное усиление характеристик
   - Стоимость: 20 Memory
   - Эффект: +5 атака на 10 секунд

### Механика колоды

- **Размер колоды**: 10 карт (стартовая колода)
- **Размер руки**: 5 карт максимум
- **Замена карт**: После разыгрывания карты, новая карта берется из колоды
- **Рандомизация**: Случайный выбор из доступных карт

### Принципы баланса

1. **Rock-Paper-Scissors**
   - Быстрые юниты > Мощные юниты > Танки > Быстрые юниты

2. **Экономика**
   - Дорогие юниты сильнее, но медленнее окупаются
   - Дешевые юниты - быстрый rush

3. **Синергия**
   - Командные юниты (Higher-Order Commander, Dynamic Dispatcher)
   - Поддержка (Indexer, API Gateway)
   - Контроль (Deadlock Trap, Abstraction Agent)

## Мета-стратегии

### Rush стратегия
- Фокус на дешевых юнитах (Basic Process)
- Быстрая атака на базу противника
- Риск: слабая защита, уязвимость к контр-атакам

### Economy стратегия
- Захват максимума узлов памяти (Allocator spam)
- Апгрейд фабрики
- Создание элитных юнитов (Lambda Sniper, Higher-Order Commander)
- Риск: медленный старт, уязвимость к rush

### Balanced стратегия
- Захват нескольких узлов
- Микс дешевых и средних юнитов
- Адаптация к действиям противника

### Control стратегия
- Фокус на контроле поля (Deadlock Trap, Abstraction Agent)
- Разведка (Reflection Spy, WebSocket Scout)
- Точечные удары (Lambda Sniper)
- Риск: требует высокого skill

## Обучающий аспект

### Педагогические цели

1. **Визуализация концепций**
   - Игроки видят абстрактные концепции в действии
   - Интерактивное взаимодействие с терминами

2. **Понимание синергий**
   - Как различные паттерны работают вместе
   - Важность архитектуры (как и в реальном коде)

3. **Стратегическое мышление**
   - Планирование архитектуры системы
   - Оптимизация ресурсов

### Примеры обучения

- **Наследование**: Inheritance Drone визуально демонстрирует переиспользование кода
- **Полиморфизм**: Polymorph Warrior показывает адаптацию к контексту
- **Дедлок**: Deadlock Trap показывает негативные последствия конкурентности
- **Рекурсия**: Recursive Bomb показывает базовый случай рекурсии

## Монетизация (будущее)

### Free-to-Play модель

**Бесплатно:**
- Полный доступ к геймплею
- Все юниты и механики
- Базовые скины

**Premium (опционально):**
- Косметические скины для юнитов
- Альтернативные доски (темы: Python, Java, Rust)
- Battle Pass с наградами
- Кастомизация Instance/Factory

### Принципы
- **Никакого Pay-to-Win**
- Все геймплейные элементы доступны бесплатно
- Только косметика за деньги
