# Быстрый старт - RTS Multiplayer Game

## Минимальные требования

- Java 17+
- PostgreSQL 12+ (или Docker)
- 4GB RAM

## Шаг 1: Настройка базы данных

### Вариант А: Локальный PostgreSQL

```bash
# Подключитесь к PostgreSQL
psql -U postgres

# Создайте базу данных
CREATE DATABASE rtsgame;

# Выйдите из psql
\q
```

### Вариант Б: Docker PostgreSQL

```bash
docker run --name rtsgame-postgres \
  -e POSTGRES_DB=rtsgame \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  -d postgres:14
```

## Шаг 2: Запуск сервера

```bash
cd rts-game

# Запуск сервера (порт 8080)
./gradlew :server:run
```

Сервер запустится и создаст необходимые таблицы автоматически.

## Шаг 3: Запуск клиента (Игрок 1)

Откройте новый терминал:

```bash
cd rts-game

# Запуск клиента
./gradlew :client:run
```

## Шаг 4: Запуск второго клиента (Игрок 2)

Откройте еще один терминал:

```bash
cd rts-game

# Запуск второго клиента
./gradlew :client:run
```

## Шаг 5: Начало игры

1. В первом клиенте нажмите **SPACE** для создания игровой сессии
2. Во втором клиенте нажмите **SPACE** (подключится к той же сессии)
3. В обоих клиентах нажмите **R** (Ready), чтобы начать игру

## Управление в игре

### Основное
- **1-5**: Выбрать карту из руки
- **ЛКМ** (левая кнопка мыши): Выбрать свой юнит или разыграть выбранную карту
- **ПКМ** (правая кнопка мыши): Переместить выбранный юнит или атаковать

### Игровой процесс
1. Выбирайте карту (кнопки 1-5)
2. Кликайте ЛКМ по полю, чтобы разыграть карту
3. Выбирайте юнит ЛКМ
4. Перемещайте его ПКМ или атакуйте врагов

## Цель игры

Уничтожьте **Instance** (базу) противника, защищая свою!

## Обозначения на поле

- **Зеленый квадрат**: Ваша база (Instance)
- **Красный квадрат**: База врага
- **Голубой квадрат**: Ваша фабрика
- **Оранжевый квадрат**: Фабрика врага
- **Желтые круги**: Свободные узлы памяти
- **Синие круги**: Ваши захваченные узлы памяти
- **Фиолетовые круги**: Узлы памяти врага
- **Зеленые точки**: Ваши юниты
- **Розовые точки**: Юниты врага

## Устранение проблем

### Сервер не запускается

```bash
# Проверьте, что PostgreSQL запущен
psql -U postgres -c "SELECT 1"

# Проверьте порт 8080
lsof -i :8080
```

### Клиент не подключается

- Убедитесь, что сервер запущен
- Проверьте логи сервера на наличие ошибок
- Убедитесь, что порт 8080 открыт

### Проблемы с производительностью

```bash
# Увеличьте память для JVM
export JAVA_OPTS="-Xmx2G"
./gradlew :client:run
```
