# RTS Multiplayer Game - MVP

Многопользовательская RTS игра на Kotlin с использованием Ktor (сервер) и LibGDX (клиент).

## Описание игры

Игра представляет собой стратегию в реальном времени, где игроки сражаются за захват ресурсов компьютера.

### Основные концепции

- **Мир**: Устройство ПК (прямоугольное поле 30x20)
- **Игроки**: Программы, борющиеся за память и ресурсы
- **Карты**: Действия определяются картами в руке игрока
- **Юниты**: Различные типы процессов, представляющие концепции ООП и программирования

### Игровые объекты

#### Базовые процессы
- **Allocator**: Захватывает узлы памяти, производит память
- **Garbage Collector**: Очищает мусор, возвращает память
- **Basic Process**: Базовый боевой юнит

#### OOP-юниты
- **Inheritance Drone**: Наследует параметры павших союзников
- **Polymorph Warrior**: Меняет тип атаки под цель
- **Encapsulation Shield**: Создает защиту
- **Abstraction Agent**: Скрывает союзников

#### Рефлексия и метапрограммирование
- **Reflection Spy**: Сканирует вражеские юниты
- **Code Injector**: Внедряет баги в фабрики врага
- **Dynamic Dispatcher**: Повышает скорость союзников

#### Асинхронность и параллелизм
- **Coroutine Archer**: Асинхронные стрелы
- **Promise Knight**: Отложенный урон при гибели
- **Deadlock Trap**: Обездвиживает атакующих юнитов

#### Функциональное программирование
- **Lambda Sniper**: Однократный смертельный выстрел
- **Recursive Bomb**: Взрывается на меньшие бомбы
- **Higher-Order Commander**: Усиливает другие юниты

#### Сетевые протоколы
- **API Gateway**: Расширяет радиус действия
- **WebSocket Scout**: Передает координаты врагов
- **RESTful Healer**: Лечит и усиливает союзников

#### Хранилища
- **Cache Runner**: Быстрый юнит для захвата кэша
- **Indexer**: Повышает урон по целям
- **Transaction Guard**: Откатывает захват при гибели

## Архитектура

### Модули

1. **shared**: Общие модели данных и события
2. **server**: Ktor-сервер, обработка игровой логики
3. **client**: LibGDX-клиент, визуализация и управление

### Технологии

- **Kotlin 1.9.21**
- **Ktor 2.3.7** (server)
- **LibGDX 1.12.1** (client)
- **PostgreSQL** (database)
- **Exposed ORM** (database access)
- **WebSockets** (real-time communication)
- **Kotlinx Serialization** (JSON)

## Требования

- JDK 17+
- PostgreSQL 12+
- Gradle 8.0+


## Запуск

### Сервер

```bash
cd rts-game
./gradlew :server:run
```

Сервер запустится на `http://localhost:8080`

### Клиент

```bash
cd rts-game
./gradlew :client:run
```

Для запуска второго клиента (второй игрок) откройте еще один терминал и выполните ту же команду.

## Игровой процесс

### Начало игры

1. Запустите клиент
2. Нажмите SPACE для создания сессии
3. Второй игрок подключается к той же сессии (автоматически)
4. Когда оба игрока готовы, нажмите R (Ready)

### Управление

- **1-5**: Выбрать карту из руки
- **ЛКМ**: Выбрать свой юнит или разыграть карту
- **ПКМ**: Переместить юнит или атаковать цель
- **R**: Готов к началу игры

### Цель

Уничтожить Instance (базу) противника, одновременно защищая свою.

## API

### HTTP Endpoints

- `GET /` - Статус сервера
- `GET /api/session/create` - Создать игровую сессию

### WebSocket

- `WS /ws/{sessionId}` - Подключение к игровой сессии

### События (Client → Server)

- `JoinGame`: Присоединиться к игре
- `PlayerReady`: Игрок готов
- `PlayCard`: Разыграть карту
- `MoveUnit`: Переместить юнит
- `AttackTarget`: Атаковать цель
- `CaptureNode`: Захватить узел памяти

### События (Server → Client)

- `GameStateUpdate`: Обновление состояния игры
- `GameStarted`: Игра началась
- `GameEnded`: Игра завершена
- `UnitSpawned`: Юнит создан
- `UnitMoved`: Юнит перемещен
- `UnitAttacked`: Атака юнита
- `UnitDied`: Юнит погиб
- `NodeCaptured`: Узел захвачен

## Архитектурные решения

- **Модульная структура**: Разделение на shared, server, client для переносимости
- **Event-driven**: Все действия передаются через события
- **WebSocket**: Реальное время для мультиплеера
- **Server-authoritative**: Вся логика на сервере (защита от читов)
- **PostgreSQL**: Сохранение сессий для аналитики
